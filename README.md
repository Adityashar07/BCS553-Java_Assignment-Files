## 🚀 How to Run the Programs

1. Clone this repository:

```bash
git clone https://github.com/Adityashar07/BCSS53-Java_Assignment-Files.git
```

2. Navigate to the repository:

```bash
cd BCSS53-Java_Assignment-Files
```

3. Open the required assignment and task folder.

4. Compile the Java program:

```bash
javac Main.java
```

5. Execute the program:

```bash
java Main
```

*Note: Replace `Main.java` and `Main` with the actual Java filename and class name when required.*
